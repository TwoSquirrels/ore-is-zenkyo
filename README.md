# ore-is-zenkyo
俺は全強

## 🎉 およー! カオスなサイト 🌈

画面中を「俺は全強」と「およー」とたくさんの絵文字が暴れ回る、超カオスなインタラクティブサイトです！😎✨

### 🚀 使い方

`index.html` をブラウザで開いてください:
```bash
open index.html
# または
python3 -m http.server 8000
# そして http://localhost:8000 にアクセス
```

### ✨ 特徴

- 🌈 15個の「俺は全強」がレインボーカラーで画面を跳ね回る
- 🎪 8個の「およー」がくるくる回転しながら移動
- 😎 20個のランダムな絵文字が浮遊
- 🖱️ マウスカーソルに反応して要素が逃げる
- 💥 クリックすると爆発エフェクトと新しい要素が追加
- 🎨 背景が3秒ごとにカラフルに変化
- ✨ マウスの軌跡にカラフルなパーティクル

### 🎯 インタラクション

- **マウスを動かす**: 要素がカーソルから逃げる + カラフルな軌跡
- **クリック**: 爆発エフェクト + 新しい絵文字/テキストが追加
- **3回クリック**: 新しい「俺は全強」が追加
- **5回クリック**: 新しい「およー」が追加

およー! 🎉
